## Тихий лог и подробные таймеры

- Уровень `INFO` по умолчанию показывает запуск и остановку, первый успешный цикл и одну сводку для циклов с загрузками, добавлением связей с альбомом или удалениями. Без изменений сообщение об успешном цикле появляется раз в 10 минут.
- `--log-level DEBUG` показывает каждый цикл, источники и цели, а также отдельные операции: скачивание, конвертацию, загрузку, проверку фото, видео и обложек, вызовы API рамки, работу с локальными метаданными и очистку временных файлов.
- Таймеры измеряют полные операции, включая ожидания и повторы. Длительность цикла не включает паузу между циклами. Долгие видеооперации также сообщают о начале и прогрессе чтения с рамки.
- Предупреждения, ошибки и обнаруженные повреждения остаются видны на уровне по умолчанию. Разовые команды сохраняют итоговые сводки. Ненулевой счётчик `linked` означает добавление уже имеющихся на рамке медиа в целевой альбом без повторной загрузки.

```sh
tfs run
tfs --log-level DEBUG run
```

Значения счётчиков и границы измерений описаны в [руководстве по логированию](https://github.com/impishMD/divoom-times-frame-sync/blob/v0.7.1/docs/ru/sync-modes.md#проверка-работы).

## Обновление

Сохраните конфигурацию и `data/`, затем перезапустите сервис после обновления. Переход с v0.7.0 не требует миграции метаданных или дополнительных проверок медиа.

```sh
docker compose pull
docker compose up -d --no-build
```

Если `TFS_IMAGE` закреплён на версии, сначала замените её на `v0.7.1`. Образы для `linux/amd64` и `linux/arm64` публикуются с тегами версии и `latest`:

```text
impishmd/divoom-times-frame-sync:v0.7.1
ghcr.io/impishmd/divoom-times-frame-sync:v0.7.1
```

Архивы исходников и Python-пакеты приложены к релизу с контрольными суммами SHA-256.
