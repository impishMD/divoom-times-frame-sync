## Быстрая инкрементальная синхронизация

Обычная синхронизация сверяет метаданные источников и записи рамки с постоянным журналом проверок. Неизменившиеся фото и видео не требуют скачивания из облака, конвертации или чтения содержимого с рамки. Новые загрузки проходят одну полную проверку вместо двух. База альбомов и журнал больше не читаются и не записываются заново для каждого неизменившегося элемента.

Логи различают совпадения по метаданным, полные проверки содержимого, скачивания, загрузки и исключения, а также показывают время синхронизации цели.

## Явная проверка целостности и восстановление

- `tfs repair --dry-run` читает файлы целиком и показывает повреждения без изменений рамки. При проблемах или ошибках возвращается ненулевой код.
- `tfs repair` проверяет все настроенные источники и цели: фотографии, видео, обложки, типы записей, отсутствие файлов или связей с альбомами. Исправные файлы повторно не загружаются.
- Отдельная исправная копия проверяется до переноса связей в затронутых обычных альбомах. Незавершённые операции сохраняются в журнале и возобновляются после прерывания; обычная синхронизация блокирует такую цель до завершения восстановления.
- Восстановление не исключает исчезнувшие из источников элементы и не переключает показ. Сетевые ошибки не считаются повреждениями. Старые повреждённые копии остаются во «Все фото»: глобального удаления нет.

## Обновление

Сохраните конфигурацию и `data/`. Первый цикл после обновления один раз прочитает существующие медиа с рамки и добавит записи о проверке; при сохранённых хешах повторно скачивать исходники не требуется. Следующие неизменившиеся циклы используют только метаданные. Перед `repair` остановите `run`: команды используют одну блокировку каталога данных.

```sh
docker compose pull
docker compose up -d --no-build
```

Если `TFS_IMAGE` закреплён на версии, сначала замените её на `v0.7.0`. Образы для `linux/amd64` и `linux/arm64`, также доступные с тегом `latest`:

```text
impishmd/divoom-times-frame-sync:v0.7.0
ghcr.io/impishmd/divoom-times-frame-sync:v0.7.0
```

Архивы исходников и Python-пакеты приложены к релизу с контрольными суммами SHA-256. Подробнее — в [руководстве repair](https://github.com/impishMD/divoom-times-frame-sync/blob/v0.7.0/docs/ru/repair.md) и [описании хранения](https://github.com/impishMD/divoom-times-frame-sync/blob/v0.7.0/docs/ru/storage.md).
