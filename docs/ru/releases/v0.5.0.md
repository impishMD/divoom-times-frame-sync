## Синхронизация видео из Google Photos

Видео из публичных альбомов Google Photos теперь синхронизируются со штатными альбомами Divoom Times Frame вместе с фотографиями. Существующая конфигурация источников Google Photos работает без изменений и без входа в Google.

- Видео публичного просмотрщика Google скачивается частями, затем преобразуется в MP4 H.264/AAC 800×1280 с обложкой WebP для автономного воспроизведения.
- Применяются те же правила mirror/append, проверка загрузки, постоянный журнал и очистка временных файлов, что и для видео Immich.
- Неизменённые ролики переиспользуются между циклами, в том числе при смене временной ссылки Google.
- Неполные загрузки, ответы с обложкой/HTML и перенаправления за пределы медиа-CDN Google отклоняются. При ошибке или незавершённой обработке видео сервис повторяет попытку, не исключая существующие элементы альбома.
- Название GitHub Release теперь содержит только версию.

Фотографии поддерживаются для Google Photos, iCloud Photos, Immich, OneDrive и Яндекс Диска. Видео — для Google Photos и Immich.

## Обновление

```sh
docker compose pull
docker compose up -d --no-build
```

Если `TFS_IMAGE` закреплён в `.env`, перед скачиванием замените версию на `v0.5.0`. Сохраните существующие `data/` и конфигурацию.

Образы для `linux/amd64` и `linux/arm64`:

```text
impishmd/divoom-times-frame-sync:v0.5.0
ghcr.io/impishmd/divoom-times-frame-sync:v0.5.0
```

К релизу приложены архивы исходников и Python-пакеты с контрольными суммами SHA-256. `container-digests.txt` содержит неизменяемые ссылки на образы. Настройка и параметры показа описаны в [README на русском](https://github.com/impishMD/divoom-times-frame-sync/blob/v0.5.0/README.ru.md) и [English README](https://github.com/impishMD/divoom-times-frame-sync/blob/v0.5.0/README.md).
