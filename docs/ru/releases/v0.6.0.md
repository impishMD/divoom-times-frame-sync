## Синхронизация видео из всех поддерживаемых сервисов

Видео из публичных альбомов iCloud Photos, OneDrive и Яндекс Диска теперь синхронизируются со штатными альбомами Divoom Times Frame. Вместе с Google Photos и Immich все пять сервисов поддерживают синхронизацию фотографий и видео. Существующая конфигурация источников работает без изменений и без входа в аккаунты.

- iCloud выбирает ресурс для скачивания видео, предпочитая версии с применёнными правками и подготовленные варианты перед оригиналом. Live Photo остаются неподвижными изображениями.
- OneDrive скачивает оригинал по подписанной ссылке без передачи анонимного токена API.
- Яндекс Диск получает свежую ссылку для отдельного элемента альбома и скачивает оригинал видео.
- Файлы скачиваются частями с проверкой размера и перенаправлений, затем преобразуются в MP4 800×1280 с H.264/AAC и обложкой WebP для автономного воспроизведения.
- Видео используют существующие режимы mirror/append, проверку загрузки, журнал синхронизации и очистку временных файлов. Неизменившиеся элементы повторно используются после перезапуска и смены подписи URL; ошибки скачивания сохраняют текущий состав альбома до следующей попытки.

## Обновление

```sh
docker compose pull
docker compose up -d --no-build
```

Если в `.env` закреплён `TFS_IMAGE`, перед скачиванием измените его версию на `v0.6.0`. Сохраните текущую конфигурацию и каталог `data/`, чтобы сервис сохранил журнал владения и метаданные для предотвращения дублей. Миграция состояния не требуется.

Образы для `linux/amd64` и `linux/arm64`, также с тегом `latest`:

```text
impishmd/divoom-times-frame-sync:v0.6.0
ghcr.io/impishmd/divoom-times-frame-sync:v0.6.0
```

К релизу приложены архивы исходников и Python-пакеты с контрольными суммами SHA-256. Файл `container-digests.txt` содержит неизменяемые ссылки на образы. Настройка источников и воспроизведения описана в [английском README](https://github.com/impishMD/divoom-times-frame-sync/blob/v0.6.0/docs/en/README.md) и [русском README](https://github.com/impishMD/divoom-times-frame-sync/blob/v0.6.0/docs/ru/README.md).
