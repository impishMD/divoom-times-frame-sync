# Divoom Times Frame Sync v0.4.0

[English](https://github.com/impishMD/divoom-times-frame-sync/blob/main/docs/en/releases/v0.4.0.md) | **Русский**

Первый релиз с пакетами сервиса для синхронизации публичных альбомов со штатными альбомами Divoom Times Frame по локальной сети.

- Публичные фотоальбомы Google Photos, iCloud Photos, Immich, OneDrive и Яндекс Диска.
- Несколько исходных альбомов каждого сервиса, объединённые или отдельные альбомы назначения и автоматическая периодическая синхронизация.
- Видео из Immich с локальным преобразованием H.264/AAC и автономным воспроизведением из памяти рамки.
- Режимы mirror и append, проверка загрузки, постоянный журнал владения и очистка временных медиафайлов после переноса.
- Инструкции по настройке на английском и русском, документация API и лицензия Apache-2.0.
- Контейнеры для Linux AMD64 и ARM64 со встроенным FFmpeg, опубликованные в Docker Hub и GHCR.

## Установка

Следуйте [руководству по настройке](https://github.com/impishMD/divoom-times-frame-sync/blob/v0.4.0/README.ru.md) ([на английском](https://github.com/impishMD/divoom-times-frame-sync/blob/v0.4.0/README.md)).

Образы контейнеров:

```text
impishmd/divoom-times-frame-sync:v0.4.0
ghcr.io/impishmd/divoom-times-frame-sync:v0.4.0
```

Оба имени выбирают подходящий образ для `linux/amd64` или `linux/arm64`. Сохраняйте `data/` между запусками, чтобы не потерять журнал синхронизации.

К релизу приложены исходники и Python-пакеты с SHA-256 в `checksums.txt`. Точные ссылки на манифесты контейнеров записаны в `container-digests.txt`.

## Ограничения этой версии

Источники должны использовать поддерживаемые публичные ссылки на альбомы. В этой версии видео поддерживается только для Immich. Mirror исключает отслеживаемые элементы из целевого альбома; сами файлы остаются в памяти рамки. Форматы ссылок и ограничения отдельных сервисов описаны в README.
