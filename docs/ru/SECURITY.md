## Сообщение об уязвимости

Сообщайте об уязвимостях приватно. Если в репозитории доступен пункт **Security → Report a vulnerability**, используйте форму приватного сообщения GitHub. Этот пункт доступен только при включённом приёме приватных сообщений об уязвимостях.

Если такой возможности нет и у вас нет приватного контакта владельца, создайте issue с просьбой предоставить канал для приватного сообщения. Не включайте в этот публичный запрос описание уязвимости, шаги эксплуатации, учётные данные или личную информацию.

В приватном сообщении укажите затронутую версию или коммит, провайдер или операцию рамки, последствия и шаги воспроизведения на отдельном альбоме с вымышленными данными. Перед отправкой логов удалите из них чувствительную информацию.

## Работа с чувствительными данными

Публичная ссылка на альбом может предоставлять доступ к фотографиям без пароля. Не публикуйте общие ссылки, токены рамки, `.env`, `sources.toml`, `data/`, дампы сетевых запросов или базы устройства в issues и pull requests.

Divoom Times Frame Sync читает исходные альбомы и меняет альбомы рамки через локальный API устройства. Журнал синхронизации хранит сведения об элементах, которыми управляет сервис, чтобы отличать их от добавленных вручную. Храните эти метаданные в постоянном каталоге с ограниченным доступом.
