# Helm-чарт 0.1.0

[English](https://github.com/impishMD/divoom-times-frame-sync/blob/chart-v0.1.0/docs/en/chart-releases/v0.1.0.md) | **Русский**

Первый Helm-чарт Divoom Times Frame Sync с приложением **0.7.1** по умолчанию.

- Один процесс, обновления Recreate, постоянный журнал и сохранение PVC по умолчанию.
- Все пять провайдеров публичных альбомов, несколько источников и целей, проверка настроек.
- Секреты из существующего Secret; ConfigMap источников содержит только имена переменных.
- Работа без root, корневая файловая система только для чтения, настройка ресурсов и размещения.
- Проверки Helm 3/4 и установка, обновление, сохранение данных во временном Kubernetes-кластере.

```sh
helm repo add divoom https://impishmd.github.io/divoom-times-frame-sync/
helm repo update
helm upgrade --install divoom-sync divoom/divoom-times-frame-sync \
  --version 0.1.0 --namespace divoom-sync --create-namespace -f values.yaml
```

Перед установкой задайте `config.frame.host`, `existingSecret` и источники. Настройки, секреты, хранилище и пример Application описаны в [руководстве Helm и Argo CD](https://github.com/impishMD/divoom-times-frame-sync/blob/chart-v0.1.0/docs/ru/helm.md).

Архив чарта приложен к релизу и опубликован в Helm-репозитории Pages. Версии и теги чарта (`chart-v…`) независимы от версий приложения и тегов образов (`v…`).
