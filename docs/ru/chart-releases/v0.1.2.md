# Helm-чарт 0.1.2

[English](https://github.com/impishMD/divoom-times-frame-sync/blob/chart-v0.1.2/docs/en/chart-releases/v0.1.2.md) | **Русский**

Добавлена опция подготовки прав PVC для драйверов, оставляющих владельцем тома root, и данных, перенесённых с другим владельцем. Она устраняет ошибки запуска вида `Permission denied: '/app/data/.lock'`.

```yaml
volumePermissions:
  enabled: true
```

По умолчанию опция выключена. При включении init-контейнер от root перед стартом сервиса рекурсивно выставляет владельца тома в UID/GID сервиса и даёт владельцу права чтения, записи и обхода каталогов. Он использует образ приложения, подключает только PVC данных и не получает секреты источников. Сам сервис продолжает работать без root. Содержимое файлов сохраняется; политика namespace должна разрешать root и необходимые capabilities init-контейнера.

В Argo CD задайте `targetRevision: 0.1.2` у источника чарта, добавьте настройку выше и выполните sync. Существующие PVC и Secret можно использовать повторно. Образ приложения остаётся **0.7.1**.

Права и случай Synology iSCSI описаны в [руководстве Helm и Argo CD](https://github.com/impishMD/divoom-times-frame-sync/blob/chart-v0.1.2/docs/ru/helm.md). Проверки чарта охватывают настройки по умолчанию и восстановление доступа к тому с владельцем root и существующими закрытыми файлами при отключённом `fsGroup`.
