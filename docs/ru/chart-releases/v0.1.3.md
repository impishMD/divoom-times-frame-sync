# Helm-чарт 0.1.3

[English](https://github.com/impishMD/divoom-times-frame-sync/blob/chart-v0.1.3/docs/en/chart-releases/v0.1.3.md) | **Русский**

Образ приложения по умолчанию обновлён до **0.7.2**. Перед опросом публичных альбомов сервис проверяет доступность API рамки, пропускает циклы при потере соединения и автоматически продолжает работу после восстановления. Повторные предупреждения о недоступности ограничены одним за 10 минут; отдельные попытки остаются видны в DEBUG.

В Argo CD установите `targetRevision: 0.1.3` у источника чарта и выполните sync. Если `image.tag` закреплён явно, обновите его до `v0.7.2` или очистите, чтобы использовать `appVersion` чарта. Явный `image.digest` по-прежнему имеет приоритет; если он задан, его нужно обновить отдельно.

Существующие Secret, PVC, настройки источников и `volumePermissions.enabled` сохраняются. Миграция метаданных не нужна. Подробнее — в [заметках о релизе приложения](https://github.com/impishMD/divoom-times-frame-sync/blob/v0.7.2/docs/ru/releases/v0.7.2.md) и [руководстве Helm](https://github.com/impishMD/divoom-times-frame-sync/blob/chart-v0.1.3/docs/ru/helm.md).
