# Helm-чарт 0.1.1

[English](https://github.com/impishMD/divoom-times-frame-sync/blob/chart-v0.1.1/docs/en/chart-releases/v0.1.1.md) | **Русский**

Исправлен запуск с большими числовыми ID пользователя. Чарт 0.1.0 мог преобразовать значение вроде `123456789` в `"1.23456789e+08"`, из-за чего приложение завершалось с ошибкой `Port, user ID and interval must be integers`.

- ID пользователя, порт и интервал синхронизации передаются строками с десятичной записью целого числа.
- Проверки чарта загружают итоговые переменные окружения через парсер конфигурации приложения и охватывают большие ID, граничные значения и большой интервал. Для проверки установки также используется большой ID.
- Образ приложения по умолчанию остаётся **0.7.1**. Менять существующие values и Secret не нужно.

Для Argo CD установите `targetRevision: 0.1.1` у источника чарта и выполните sync. Для Helm:

```sh
helm repo update
helm upgrade divoom-sync divoom/divoom-times-frame-sync \
  --version 0.1.1 --namespace divoom-sync -f values.yaml
```

Используйте своё имя релиза и namespace. Подробнее — в [руководстве Helm и Argo CD](https://github.com/impishMD/divoom-times-frame-sync/blob/chart-v0.1.1/docs/ru/helm.md).
