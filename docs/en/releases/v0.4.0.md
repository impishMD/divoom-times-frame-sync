# Divoom Times Frame Sync v0.4.0

**English** | [Русский](https://github.com/impishMD/divoom-times-frame-sync/blob/main/docs/ru/releases/v0.4.0.md)

First packaged release of the service for syncing public albums to native Divoom Times Frame albums over the local network.

- Public photo albums from Google Photos, iCloud Photos, Immich, OneDrive, and Yandex Disk.
- Multiple source albums per service, combined or separate destination albums, and automatic periodic synchronization.
- Immich video support with local H.264/AAC conversion and autonomous playback from the frame's memory.
- Mirror and append modes, upload verification, a persistent ownership journal, and cleanup of temporary media after upload.
- English and Russian setup instructions, API documentation, and Apache-2.0 licensing.
- Container images for Linux AMD64 and ARM64, with FFmpeg included, published to Docker Hub and GHCR.

## Install

Follow the [configuration and setup guide](https://github.com/impishMD/divoom-times-frame-sync/blob/v0.4.0/README.md) ([in Russian](https://github.com/impishMD/divoom-times-frame-sync/blob/v0.4.0/README.ru.md)).

Container images:

```text
impishmd/divoom-times-frame-sync:v0.4.0
ghcr.io/impishmd/divoom-times-frame-sync:v0.4.0
```

Both names select the correct image for `linux/amd64` or `linux/arm64`. Keep the `data/` directory between runs to preserve the sync journal.

Source archives and Python packages are attached, with SHA-256 checksums in `checksums.txt`. Exact container manifest references are recorded in `container-digests.txt`.

## Current scope

Sources must use supported public album links. Video is currently supported for Immich only. Mirror mode removes managed items from the destination album, while the media files remain in the frame's memory. See the README for sharing link formats and source-specific limitations.
