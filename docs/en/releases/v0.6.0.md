# v0.6.0

**English** | [Русский](https://github.com/impishMD/divoom-times-frame-sync/blob/v0.6.0/docs/ru/releases/v0.6.0.md)

## Video sync for every supported service

Videos from public iCloud Photos, OneDrive, and Yandex Disk albums now sync to native Divoom Times Frame albums. Together with Google Photos and Immich, all five supported services now provide both photo and video sync. Existing source configurations work without changes or account sign-in.

- iCloud chooses a downloadable video resource, preferring rendered edits and prepared versions before falling back to the original. Live Photos remain still images.
- OneDrive downloads the original through its signed URL without forwarding the anonymous API token.
- Yandex Disk requests a fresh download URL for the individual album item and downloads the original video.
- Downloads are streamed with size and redirect checks, then converted to 800×1280 H.264/AAC MP4 with a WebP cover for autonomous playback.
- Videos follow the existing mirror/append rules, upload verification, sync journal, and temporary-file cleanup. Unchanged items are reused across restarts and URL signature changes; failed downloads preserve existing album members for a retry.

## Update

```sh
docker compose pull
docker compose up -d --no-build
```

If `TFS_IMAGE` is pinned in `.env`, update its version to `v0.6.0` before pulling. Keep the existing configuration and `data/` directory so the service retains ownership and deduplication metadata. No state migration is required.

Images for `linux/amd64` and `linux/arm64`, also tagged `latest`:

```text
impishmd/divoom-times-frame-sync:v0.6.0
ghcr.io/impishmd/divoom-times-frame-sync:v0.6.0
```

Source archives and Python packages are attached with SHA-256 checksums. `container-digests.txt` records the immutable image references. See the [English README](https://github.com/impishMD/divoom-times-frame-sync/blob/v0.6.0/docs/en/README.md) or [Russian README](https://github.com/impishMD/divoom-times-frame-sync/blob/v0.6.0/docs/ru/README.md) for configuration and playback settings.
