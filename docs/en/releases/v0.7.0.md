# v0.7.0

**English** | [Русский](https://github.com/impishMD/divoom-times-frame-sync/blob/v0.7.0/docs/ru/releases/v0.7.0.md)

## Fast incremental sync

Normal sync now matches source metadata and native frame records against a persistent verification journal. Unchanged photos and videos need no cloud downloads, conversion, or media readback from the frame. New uploads receive one full verification instead of two. Album database reads and journal writes are no longer repeated for every unchanged item.

Logs distinguish metadata matches, full content checks, downloads, uploads, and removals, and include the destination's elapsed sync time.

## Explicit integrity checks and recovery

- `tfs repair --dry-run` reads full contents and reports damage without changing the frame. Detected problems or errors return a nonzero exit code.
- `tfs repair` checks all configured sources and destinations, including photos, videos, covers, media types, and missing records or album links. Healthy files are not uploaded again.
- Recovery verifies a separate replacement before transferring links in affected ordinary albums. Pending operations are journaled and can resume after interruption; normal sync blocks a destination while its repair is unfinished.
- Repair does not prune source absences or switch playback. Network failures are not treated as corrupt files. Old damaged copies remain in All Photos; no global deletion is performed.

## Upgrade

Keep configuration and `data/`. The first sync after upgrading adds verification records by reading existing frame media once; saved fingerprints avoid cloud redownloads. Subsequent unchanged cycles use metadata only. Stop `run` before invoking repair because both commands share the data-directory lock.

```sh
docker compose pull
docker compose up -d --no-build
```

If `TFS_IMAGE` is pinned, update it to `v0.7.0` first. Multi-platform images for `linux/amd64` and `linux/arm64`, also tagged `latest`:

```text
impishmd/divoom-times-frame-sync:v0.7.0
ghcr.io/impishmd/divoom-times-frame-sync:v0.7.0
```

Source archives and Python packages are attached with SHA-256 checksums. See the [repair guide](https://github.com/impishMD/divoom-times-frame-sync/blob/v0.7.0/docs/en/repair.md) and [storage guide](https://github.com/impishMD/divoom-times-frame-sync/blob/v0.7.0/docs/en/storage.md).
