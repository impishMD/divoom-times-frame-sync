# Helm chart 0.1.0

**English** | [Русский](https://github.com/impishMD/divoom-times-frame-sync/blob/chart-v0.1.0/docs/ru/chart-releases/v0.1.0.md)

The first Helm chart for Divoom Times Frame Sync, defaulting to application **0.7.1**.

- One worker with Recreate updates, persistent journal storage, and PVC retention by default.
- All five public album providers, multiple sources and destinations, and configuration validation.
- Credentials supplied through an existing Secret; only variable names appear in the source ConfigMap.
- Non-root execution, a read-only container root filesystem, configurable resources and scheduling.
- Helm 3/4 checks and installation/upgrade/storage checks in an isolated Kubernetes cluster.

```sh
helm repo add divoom https://impishmd.github.io/divoom-times-frame-sync/
helm repo update
helm upgrade --install divoom-sync divoom/divoom-times-frame-sync \
  --version 0.1.0 --namespace divoom-sync --create-namespace -f values.yaml
```

Set `config.frame.host`, `existingSecret`, and your sources before installation. See the [Helm and Argo CD guide](https://github.com/impishMD/divoom-times-frame-sync/blob/chart-v0.1.0/docs/en/helm.md) for values, credentials, storage, and an Application example.

The attached chart archive is published in the Pages Helm repository. Chart versions and tags (`chart-v…`) are independent of application versions and image tags (`v…`).
