# Helm chart 0.1.3

**English** | [Русский](https://github.com/impishMD/divoom-times-frame-sync/blob/chart-v0.1.3/docs/ru/chart-releases/v0.1.3.md)

Updates the default application image to **0.7.2**. The worker checks frame API availability before querying public albums, skips cycles during connection failures, and resumes automatically. Repeated outage warnings are limited to once every 10 minutes; individual attempts remain visible at DEBUG.

In Argo CD, set the chart source's `targetRevision` to `0.1.3` and sync. If `image.tag` is explicitly pinned, update it to `v0.7.2` or clear it to follow the chart's `appVersion`. An explicit `image.digest` still takes priority and must be updated separately if used.

Existing Secrets, PVCs, source settings, and `volumePermissions.enabled` can be kept. No metadata migration is required. See the [application release notes](https://github.com/impishMD/divoom-times-frame-sync/blob/v0.7.2/docs/en/releases/v0.7.2.md) and [Helm guide](https://github.com/impishMD/divoom-times-frame-sync/blob/chart-v0.1.3/docs/en/helm.md).
