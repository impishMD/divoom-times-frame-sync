# Helm chart 0.1.1

**English** | [Русский](https://github.com/impishMD/divoom-times-frame-sync/blob/chart-v0.1.1/docs/ru/chart-releases/v0.1.1.md)

Fixes startup with large numeric user IDs. Chart 0.1.0 could render a value such as `123456789` as `"1.23456789e+08"`, causing the application to exit with `Port, user ID and interval must be integers`.

- User ID, port, and sync interval are explicitly rendered as decimal integer strings.
- Chart checks load the rendered environment with the application's configuration parser and cover large IDs, boundary values, and a long interval. The installation fixture also uses a large user ID.
- The default application image remains **0.7.1**. Existing values and Secrets need no changes.

For Argo CD, set the chart source's `targetRevision` to `0.1.1` and sync. For Helm:

```sh
helm repo update
helm upgrade divoom-sync divoom/divoom-times-frame-sync \
  --version 0.1.1 --namespace divoom-sync -f values.yaml
```

Use your existing release name and namespace. See the [Helm and Argo CD guide](https://github.com/impishMD/divoom-times-frame-sync/blob/chart-v0.1.1/docs/en/helm.md).
